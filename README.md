# 🚀 Graph Databases & Analytics — From Basics to Real-World Applications

> A hands-on, notebook-driven course to master graph databases, graph algorithms, and graph machine learning — with a strong focus on **fraud detection, AML, and real-world use cases**.

---

## 🌟 Why This Repository?

Most graph learning resources are either:

* Too theoretical ❌
* Too shallow ❌
* Or disconnected from real-world problems ❌

This course is different.

* ✅ Learn **from first principles → production-ready systems**
* ✅ Build **intuitive + practical understanding**
* ✅ Apply concepts to **fraud detection, credit risk, and recommendations**
* ✅ Get hands-on with **real tools used in industry**

---

## 🧠 What You’ll Learn

* Graph fundamentals (nodes, edges, properties)
* Graph traversal (BFS, DFS, shortest paths)
* Core algorithms (centrality, community detection)
* Link prediction & similarity
* Graph embeddings (Node2Vec, GraphSAGE)
* Graph Machine Learning (GNN basics)
* Graph databases & querying
* Real-world applications (Fraud, AML, Credit Risk)

---

## 🛠️ Tech Stack

* Python
* NetworkX
* Neo4j
* Amazon Neptune
* PyTorch Geometric

## 🔥 Capstone Project

### 🕵️ Detect Fraud Rings Using Graph Analytics

You will build a complete pipeline:

* Construct a **transaction graph**
* Detect **fraud communities**
* Identify **mule accounts using centrality**
* Predict suspicious links
* Generate **ML-ready features**
* Train a fraud detection model
