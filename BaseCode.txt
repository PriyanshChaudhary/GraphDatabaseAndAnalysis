

# 📘 **Notebook 01 — Graph Fundamentals**

## 🧠 Introduction

Graphs are a powerful way to represent relationships.

A graph consists of:

* **Nodes (Vertices)** → entities (users, accounts)
* **Edges** → relationships (transactions, connections)

## ⚙️ Setup

# Install if needed
# !pip install networkx matplotlib

import networkx as nx
import matplotlib.pyplot as plt

## 🔹 Create a Simple Graph

G = nx.Graph()

# Add nodes
G.add_node("A")
G.add_node("B")

# Add edge
G.add_edge("A", "B")

print("Nodes:", G.nodes())
print("Edges:", G.edges())

## 🔹 Add Multiple Nodes & Edges

G.add_nodes_from(["C", "D", "E"])
G.add_edges_from([("A", "C"), ("B", "D"), ("C", "E")])

## 🔹 Visualize the Graph

plt.figure(figsize=(5,5))
nx.draw(G, with_labels=True, node_color='lightblue', node_size=2000)
plt.show()

## 🔹 Directed Graph

DG = nx.DiGraph()
DG.add_edge("A", "B")
DG.add_edge("B", "C")

nx.draw(DG, with_labels=True, node_color='lightgreen')
plt.show()

## 🔹 Weighted Graph

WG = nx.Graph()
WG.add_edge("A", "B", weight=5)
WG.add_edge("B", "C", weight=2)

for u, v, data in WG.edges(data=True):
    print(f"{u} -> {v} weight: {data['weight']}")

## 🔹 Convert Tabular Data → Graph

import pandas as pd

data = {
    "source": ["A", "A", "B", "C"],
    "target": ["B", "C", "D", "E"]
}

df = pd.DataFrame(data)

G = nx.from_pandas_edgelist(df, source="source", target="target")

nx.draw(G, with_labels=True)
plt.show()

## ✅ Summary

* Graph = Nodes + Edges
* Types: Directed, Undirected, Weighted
* Can convert real data into graphs

## 🧠 What You’ll Learn

* Connected Components

## 🔹 Connected Components

G = nx.Graph()
G.add_edges_from([
    ("A","B"), ("B","C"),
    ("D","E")
])

components = list(nx.connected_components(G))
print("Connected Components:", components)

💡 **Fraud Insight:** Each component = potential fraud cluster

## 🔹 Shortest Path (Dijkstra)

G = nx.Graph()
G.add_weighted_edges_from([
    ("A","B",1),
    ("B","C",2),
    ("A","C",4)
])

path = nx.dijkstra_path(G, "A", "C")
distance = nx.dijkstra_path_length(G, "A", "C")

print("Shortest path:", path)
print("Distance:", distance)

## 🔹 Triangle Count

G = nx.Graph()
G.add_edges_from([
    ("A","B"), ("B","C"), ("C","A"),  # triangle
    ("C","D")
])

triangles = nx.triangles(G)
print("Triangle count per node:", triangles)

💡 **Fraud Insight:** High triangles = tightly connected group

## 🔹 Visualize Triangles

nx.draw(G, with_labels=True, node_color='orange')
plt.show()

# 📘 **Notebook 04 — Centrality (Node Importance)**

## 🧠 Why Centrality?

Centrality helps identify:

* Influential nodes
* Fraud orchestrators
* Key intermediaries (mule accounts)

## ⚙️ Setup

import networkx as nx
import matplotlib.pyplot as plt

## 🔹 Create Graph

G = nx.Graph()
edges = [("A","B"), ("A","C"), ("B","D"), ("C","D"), ("D","E")]
G.add_edges_from(edges)

nx.draw(G, with_labels=True)
plt.show()

## 🔹 Degree Centrality

deg_cent = nx.degree_centrality(G)
print("Degree Centrality:", deg_cent)

## 🔹 Betweenness Centrality

bet_cent = nx.betweenness_centrality(G)
print("Betweenness Centrality:", bet_cent)

💡 High = potential fraud intermediary

## 🔹 Closeness Centrality

close_cent = nx.closeness_centrality(G)
print("Closeness Centrality:", close_cent)

## 🔹 PageRank

pagerank = nx.pagerank(G)
print("PageRank:", pagerank)

## 🔹 Visualization (Node Size by Importance)

sizes = [v * 3000 for v in deg_cent.values()]

nx.draw(G, with_labels=True, node_size=sizes)
plt.show()

## ✅ Summary

* Degree → popularity
* Betweenness → control point
* PageRank → influence

# 📘 **Notebook 05 — Community Detection**

## 🧠 Why Communities?

Used to detect:

* Fraud rings
* Customer segments

## 🔹 Create Graph

import networkx as nx
import matplotlib.pyplot as plt

G = nx.karate_club_graph()
nx.draw(G, node_size=50)
plt.show()

## 🔹 Connected Components

components = list(nx.connected_components(G))
print("Components:", components)

## 🔹 Label Propagation

communities = nx.algorithms.community.label_propagation_communities(G)
communities = list(communities)

print("Communities:", communities)

## 🔹 Visualize Communities

color_map = []
for node in G:
    for i, comm in enumerate(communities):
        if node in comm:
            color_map.append(i)

nx.draw(G, node_color=color_map, with_labels=True)
plt.show()

## 💡 Fraud Insight

Clusters = potential fraud rings

# 📘 **Notebook 08 — Graph Embeddings (Node2Vec)**

## 🧠 Why Embeddings?

Convert graph → ML features

## ⚙️ Install

# !pip install node2vec

## 🔹 Generate Embeddings

from node2vec import Node2Vec

G = nx.karate_club_graph()

node2vec = Node2Vec(G, dimensions=16, walk_length=10, num_walks=50)
model = node2vec.fit()

model.wv['0']

## 🔹 Visualize Embeddings

from sklearn.decomposition import PCA

X = [model.wv[str(i)] for i in G.nodes()]
pca = PCA(n_components=2)
coords = pca.fit_transform(X)

plt.scatter(coords[:,0], coords[:,1])
plt.show()

## 💡 Insight

Similar nodes → closer in embedding space

# 📘 **Notebook 09 — Graph Machine Learning**

## 🧠 Goal

Use graph features for ML

## 🔹 Create Features

deg = nx.degree_centrality(G)
pagerank = nx.pagerank(G)

features = []
for node in G.nodes():
    features.append([deg[node], pagerank[node]])

## 🔹 Dummy Labels

labels = [0 if i < 10 else 1 for i in range(len(features))]

## 🔹 Train Model

from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier()
model.fit(features, labels)

## 💡 Insight

Graph features improve ML performance
